> 會被排程器沖掉對話的瀏覽器上，整條產線跟著它一起脆弱。

## 一句話結論

**通了，但還沒到 Gemini 的品質。** 構圖與角色都能鎖住，卡在「紅酒漬」和「黑點眉」兩個細節。

## 四輪實測（對照圖在 `本機生圖測試/`）

### 第 1 輪：IP-Adapter 參數掃描（雙狗參考圖，cfg 1.8）

掃 weight 0.55/0.70/0.85 × start_at 0.0/0.2，固定 seed。

- ✅ **角色鎖住了**：白吉娃娃、藍項圈、銀吊牌，`start_at=0.2` 那排特別穩
- ❌ **哈士奇完全沒出現**（prompt 明寫也沒用）
- ❌ 紅酒漬變成「一杯完整的紅酒放在地上」

### 第 2 輪：把 cfg 拉到 2.5 / 3.5

- 🟡 第二隻狗出現了，**但是小型犬不是哈士奇**
- ❌ 吉娃娃的純白被染成棕白 —— cfg 拉高會削弱 IP-Adapter 的角色鎖

### 第 3 輪：只用 `taco_face.png` 單狗參考圖

想法是「哈士奇是常見品種，交給 prompt 就好」。結果：**哈士奇還是生不出來。**

### 第 4 輪：加上 ControlNet 深度圖 ← **突破點**

拿以前 Gemini 生的 `d9s1_scene.jpg` 當構圖模板，抽深度圖餵 ControlNet。

| | 純 IP-Adapter | ＋ControlNet |
|---|---|---|
| 兩隻狗都在、位置正確 | ❌ | ✅ |
| 吉娃娃純白 | ❌ 被染色 | ✅ |
| 藍項圈＋銀吊牌 | ✅ | ✅ |

最佳參數：`cfg 3.0 / steps 8 / ip_weight 0.65 / ip_start 0.25 / cn_strength 0.85`

## 最重要的一條發現

**IP-Adapter 管得住「這隻狗長什麼樣」，管不住「畫面該有幾隻狗、誰站哪裡」。**

構圖是空間資訊，文字講一百次都不會準，只能用 ControlNet 當成**圖像**硬塞進去。
隔壁卡通農場專案踩過一模一樣的坑（他們是姿勢改不動），解法也一樣。

## 第 5~7 輪：追紅酒漬（8/11 下午）

### 一個先講的教訓：不要在同一個 workflow 裡現抽深度圖

DA3 ＋ SDXL ＋ IP-Adapter ＋ ControlNet 一起載，這台 16 GB 的機器直接
`Fatal Python error: Aborted`，ComfyUI 整個進程掛掉。佇列卡在 `running=1`
二十分鐘零產出，**看起來像「很慢」其實是死了**。

修法：`make_depth.py` 把深度圖抽一次存成 PNG（只要 4 秒），
生成時用 `--depth` 讀進來。同一張模板算出來的深度圖永遠一樣，本來就沒理由重算。
拆開之後每張生成 **18~34 秒**，也不再崩。

### 第 5 輪：改寫 prompt 措辭 → 完全無效

三種寫法（`stain` / `soaked liquid` / `puddle`）生出來**幾乎一模一樣**，
都是白色泡沫。證明**文字不是變數**。

### 第 6 輪：調 ControlNet 的作用範圍 → 找到真兇

| 參數 | 結果 |
|---|---|
| `cn_end 0.85`（管到最後） | 酒漬變成**塗鴉般的深色線條** |
| `cn_strength 0.60` | 變成一團**白色布狀物** |
| `cn_strength 0.45` | 酒漬**整個消失** |

不管強弱都救不了 → 問題不在強度，在**深度圖本身餵了錯的資訊**：
DA3 把攤平在地毯上的液體誤判成有高低起伏的物體，留下一堆假輪廓，
ControlNet 只是忠實照做。

### 第 7 輪：抹平深度圖的地板區域 → 成功長出液體

`clean_depth.py`：地板區域套中值濾波磨掉假細節，只保留狗的剪影。
配 `cn_strength 0.70 / cn_end 0.50 / cfg 3.5 / seed 424242`
**終於生出真正的深紅色液體灘**（`本機生圖測試/最佳結果-clean2.png`）。

⚠️ 但 seed 影響極大：同參數換一顆 seed，酒漬就變成散落的紅色圓點。
**這代表它還不穩定，不是「調好了」，是「抽中了」。**

## 目前的能力邊界（誠實版）

| 項目 | 本機做得到嗎 |
|---|---|
| 角色外觀（白毛、藍項圈、銀吊牌） | ✅ 穩定 |
| 構圖（兩隻狗的位置） | ✅ 穩定（靠 ControlNet 深度圖） |
| 大範圍場景（客廳、地毯、沙發） | ✅ 穩定 |
| **地上的液體／污漬** | 🟡 **抽獎**，同參數換 seed 就走鐘 |
| **黑點眉** | ❌ 生不出來（Veo、Pixverse 也都掉） |

**結論：本機生圖適合「角色 ＋ 基本構圖」的題材，不適合依賴精細場景細節當梗的題材。**
紅酒片的梗正好是「地毯上的污漬愈擦愈大」，是最難的那一類。

選題時避開「地上的液體／泡沫／粉末」這種細節梗，本機生圖就完全夠用。
