## 關鍵問題：調好了，還是抽中了？

### 答案：**抽中了。**

### 可用水準的張數

- **七項全通過：0 張**
- **勉強可用（改一兩處就能上）：1 張（888999）**
- **不可用：3 張（424242、100001、555777）**

依賢賢自己的判準——「四張裡只有一兩張及格就是抽獎」——**1 張** 明確落在抽獎那邊。

### 為什麼判定是抽獎

分清楚「誰在穩、誰在飄」就很清楚了：

**穩住的（4/4 一致）——都是 ControlNet 在管的東西**
- 兩隻狗的站位、姿勢、鏡頭距離、視線方向：四張幾乎可以重疊
- 吉娃娃的白毛、藍項圈、銀吊牌：四張都在

**全飄的（每個 seed 一個樣）——都是 prompt 在管的東西**
- 哈士奇的品種：狐狸犬 → 狐狸犬 → 狐狸犬 → 棕色迷你哈士奇
- 地毯：灰米平織 → 整片深紅長毛 → 米白織紋 → 米白厚長毛
- 酒漬：一灘＋滿地紅點 → 完全消失 → 完整一灘＋酒杯 → 完整一灘但沒杯子

也就是說，這組參數穩住的只有**構圖**，沒有穩住**內容**。而失敗的都不是同一個地方，這正是抽獎的定義：不是「有一個固定的小毛病」，是「每次壞在不同地方」。

### 三個看得出來的病因

1. **IP-Adapter 把兩隻狗的外觀平均掉了**
   參考圖是一張「吉娃娃＋哈士奇」的合照，IP-Adapter weight 0.65 是把**整張圖的風格**餵給整個畫面，不會分辨「這隻要像左邊那隻、那隻要像右邊那隻」。結果就是哈士奇被吉娃娃的白色短毛特徵拉過去，四張裡三張變成白色狐狸犬。
   → 解法方向：分區 IP-Adapter（regional / attention mask），或哈士奇單獨給一張參考圖。

2. **紅色只有一份預算**
   100001 的地毯變紅時，酒漬就不見了；地毯保持白色的兩張（555777、888999）酒漬才成立。模型把「深紅色」這個訊號放到地毯或放到酒漬，二選一。
   → 解法方向：地毯的白色要寫得比酒漬更硬（例如 white rug 放在句首並加權），或用 inpaint 分兩步做。

3. **黑點眉 4/4 全失**
   參考圖裡吉娃娃額頭那兩顆黑點是這個 IP 的招牌，IP-Adapter 0.65 一張都沒還原出來。這種小面積特徵靠 IP-Adapter 是撈不回來的。
   → 解法方向：LoRA，或最後用 inpaint 補點。

4. **體型差 4/4 全失**
   四張的「大狗」都只有小狗的 1.3～1.4 倍高，而且位置更遠 → 換算成真實體型只有中小型犬。這是 ControlNet depth 鎖姿勢的副作用：深度圖把兩隻狗的相對大小也一起鎖死了，而那張深度圖裡的比例本來就不夠誇張。
   → 解法方向：改用比例正確的 depth 來源，或降 ControlNet strength 讓 prompt 的 large husky 有空間長大。

### 一句話結論

構圖已經鎖住了，內容還在擲骰子。現在收工等於接受「平均每四次抽一次」的成功率；要能量產，下一步不是再換 seed 試，是**先把哈士奇跟吉娃娃的參考來源拆開**——這是四張裡壞得最一致、也最致命的一項（配角外觀 0/4）。
