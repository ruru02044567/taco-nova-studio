# 舊版設定（video-01 用，封存參考）

## 主角：Taco

- 迷你奶油白吉娃娃，**左耳一塊焦糖色斑**（頻道辨識物，每支都要看得到）
- 超大圓深棕眼睛、誇張的大尖耳
- 細藍色項圈＋小銀色圓牌（第二辨識物）
- 個性：好奇闖禍 → 連環掩蓋越蓋越糟 → 被抓包裝無辜
- **表情方向（賢賢 8/6 拍板）：奸詐一點、眼睛睜大**——眼神要「wide open and alert with a sly cunning glint」＋嘴角一抹得意壞笑，像在計劃什麼的小軍師，不要無辜呆萌臉
  - 定裝照 v2（奸詐版）＝ `taco-ref-v2-sly.jpg`，**video-02 起當標準參考圖**
  - video-01 前 3 鏡已用 v1 舊臉拍完，後 3 鏡只在 prompt 加奸詐眼神字句、參考圖不換，避免中途換臉穿幫
- 跟 Jeffy 的區隔：Jeffy 是純白＋粉項圈；Taco 有焦糖耳斑＋藍項圈，遠看就分得出來

## 配角：Bruno

- 巨大黑色拉布拉多，永遠蜷在灰沙發上熟睡
- 功能：世界毀滅也叫不醒的目擊者；之後可發展「被嫁禍」戲份
- 每支影片都要出現在背景

## 場景：家（客廳為主）

- 明亮現代客廳：淺木地板、灰色布沙發、午後暖窗光
- 手機隨手拍感、地板高度視角、淺景深
- 廚房戲沿用同風格（暖木櫥櫃）

## 劇情公式（60 秒六幕升級版）

1. 災難現場＋看鏡頭（0–10s）
2. 掩蓋失敗 ×1（10–20s）
3. 掩蓋失敗 ×2、災難升級（20–30s）
4. 掩蓋失敗 ×3、荒謬到頂（30–40s）
5. 主人來了、緊急偽裝（40–50s）
6. 裝無辜＋背景打臉的 punchline、Bruno 熟睡（50–60s）
