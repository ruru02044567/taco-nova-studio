# 學習流程 App —— 交接規格

> 建立：2026-08-30｜來源：Claude Code 網頁版對話
> 這份給接手的 Claude 看。讀完就能直接動工，不用再問一遍。

## 一句話

把「六步提示詞鏈」做成一個**會記住進度**的工具，以後想學任何一門學問都照同一套流程跑。

---

## 一、六個提示詞（原文，這是核心資產）

【主題】是留空給使用者填的。

### 規劃階段 —— 每個主題只做一次

**1｜分級路徑**
```
請把【主題】拆成 5 個難度層級，告訴我如何從 Level 1 初學者進步到
Level 5 進階者，並為每一階段設定明確的學習目標與通關標準。
```

**2｜學習計畫**
```
我想快速學會【主題】。請替我制定一份 20 小時學習計畫，聚焦在能產生
80% 成果的 20% 核心概念。將計畫拆成 10 次、每次 2 小時，附上最佳學習
資源，並在每次結束時安排 15 分鐘複習。
```

**3｜資源清單**
```
請列出 5 個最適合快速學習【主題】的優質資源，可以是書籍、影片、課程
或專家。說明每一個資源能教我什麼，以及它為什麼值得我投入時間。
```

### 執行階段 —— 每一次上課都跑一輪

**4｜費曼法**
```
請用最簡單的方式向我解釋【主題】，接著讓我用自己的話重新說明。指出我
的錯誤，重新教我沒理解的部分，並重複這個過程，直到我能獨立解釋清楚。
```

**5｜一頁筆記**
```
請把【主題】的核心概念整理成一頁筆記。使用條列、簡單圖解與實際例子，
讓我能在 5 分鐘內完成複習。
```

**6｜測驗檢查**
```
我剛學完【主題】。請依序問我 10 題難度逐漸提高的問題，檢查我的理解
程度。每次回答後都替我評分，指出錯誤，並解釋正確答案。
```

## 二、流程規則

```
規劃（做一次）：  1 分級 → 2 計畫 → 3 資源
                        ↓
執行（每次上課）： 4 費曼 → 5 筆記 → 6 測驗
                        ↑         ↓
                        └── 沒過就回第 4 步 ──┘
```

- **這是迴圈，不是直線。** 第 6 步沒通過就回第 4 步重跑那個概念。
- 第 2 步（學習計畫）本身已含「附上最佳學習資源」，跟第 3 步重疊。
  實務上先跑第 2 步拿粗的資源，覺得不夠再用第 3 步深挖，不必兩個都跑。

## 三、App 要解決什麼（重要，別做錯方向）

**六段提示詞本身是文字，貼進 Claude 就能用 —— 光是「把文字收好」不需要 App，記事本就夠。**

App 真正該加的只有兩件事：

| # | 功能 | 為什麼只有 App 做得到 |
|---|---|---|
| **1** | **記住進度** —— 現在哪個主題、第幾次課（n/10）、卡在哪一級（L1–L5） | 對話視窗會忘記，這是聊天補不了的洞 |
| **2** | **累積產出** —— 每次的一頁筆記、每次測驗的分數與錯題，存在同一個地方 | 學了三個主題後，那就是使用者自己的知識庫 |

其他（按鈕複製提示詞、排程提醒）都是配菜，不是重點。

## 四、做法評估與結論

| 方案 | 成本 | 拿到什麼 | 缺點 |
|---|---|---|---|
| **A｜Claude Code skill** | 低 | `/learn 主題` 一個指令跑完六步 | 只在 Claude Code 裡能用，進度要自己存檔 |
| **B｜一頁網頁 App** ⭐ | 中 | 手機電腦都能開，**會記進度、存筆記、記分數** | 不會出現在 App Store |
| **C｜原生手機 App** | 高 | 桌面圖示、推播 | 開發者帳號＋審核＋長期維護，自用工具划不來 |

**結論：做 B，順手做 A。**

- **B 是主力** —— 能做到全部需求，點網址就開，不用安裝、不用審核、隨時能改。
- **A 很便宜順手做** —— 一個 markdown 檔的事。在電腦前工作用 A，在外面用 B。
- **C 只有要拿去賣才划算**，自用不做。

## 六、下一步建議

**先手動跑完一次第 4→5→6 步**（用 `AI四軌學習計畫.html` 裡 C 軌第 1 次課當題材，約 2 小時），
再開始做 App。

理由：跑過一次就會發現一兩個跟想像不一樣的地方 —— 例如某一步根本用不到、
或少了「記下我問過但沒懂的問題」這種欄位。**那時候做出來的 App 會準很多。**

不過這是使用者的判斷。若他想先有工具再開始，直接做 B 也完全合理。

## 七、做 B 的時候要記住

- 使用者是**非工程師的台灣使用者**，介面全繁體中文
- 手機看的時間比電腦多 → 手機優先
- 深色淺色都要能讀
- 已有兩份同系列文件可參考風格：`學習/` 底下那兩個 HTML
