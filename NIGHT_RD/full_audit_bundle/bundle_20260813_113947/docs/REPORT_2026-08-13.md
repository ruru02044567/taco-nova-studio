# EXP-05：拿掉 IP-Adapter（意外發現）

## 為什麼做

EXP-03 顯示 Nova 的臉在所有權重下都一樣 → 懷疑 LoRA 根本擠不進去。
依「三次同樣失敗就改變數種類」原則，**把 IP-Adapter 拿掉**，只留 ControlNet ＋ LoRA。

## 結果 🔴

| 組別 | Nova 眼睛 |
|---|---|
| A 無 LoRA、無 IP-Adapter | **異色瞳（一藍一棕）** |
| B V1 0.45 | 偏藍灰 |
| **C V2 0.45** | **偏藍，臉型最像哈士奇** |
| D V2 0.70 | 糊掉，超出可用上限 |

**只要拿掉 IP-Adapter，眼睛就開始出現藍色。**

## 結論：藍眼失敗的真兇是 IP-Adapter

IP-Adapter 用 `duo_full.png` 當參考，**那張圖裡 Nova 的眼睛是清楚的藍色**，
但 IP-Adapter 沒有把眼睛顏色帶過來，反而把它拉成棕色。

這跟「黑點眉撈不回來」是**同一類問題**：
CLIP-Vision 編碼在壓縮整張參考圖時，丟失了小面積的顏色細節。

> **這推翻了先前的歸因。** 我們一直把 Nova 的身份問題算在「LoRA 還不夠好」上，
> 實際上在正式產線的組合裡，是 IP-Adapter 蓋掉了 LoRA。

# EXP-04：髒污顏色對照實驗

## 假設

「白麵粉附著在純白短毛上，視覺對比接近於零，所以模型畫不出來。」

## 第一次測試：失敗（我自己的錯）

四組（白／淺灰／淺棕／黑）**全部生出乾淨的狗，毛上完全沒有粉末**。
一度以為推翻了對比假設。

查證後發現是**我的 prompt 寫太長**：88～100 token，超過 CLIP 的 77 上限，
風格與光線描述被截掉，四組被壓成同樣的乾淨狗。

## 第二次測試：修正 prompt 長度（29～41 token）

| 組別 | 髒污顏色 | 毛上有沒有附著 |
|---|---|---|
| A | 白粉 | ❌ 幾乎看不出來（狗站在白粉堆裡，但毛是乾淨的） |
| B | 淺灰粉 | ❌ 幾乎看不出來 |
| C | 淺棕粉 | ❌ 只有腳沾到一點 |
| **D** | **黑漆／黑煙灰** | ✅ **明顯附著**——臉上、耳朵有黑點，身上大片黑色 |

## 結論：**對比假設成立** ✅

**深色髒污能附著到白毛上並清楚可見；淺色（白／灰／棕）都不行。**

這同時解釋了三件先前分開觀察到的事：
1. D4S1 原始 10 秒版的粉塵效果弱 → **不是 i2v 的問題**
2. 夜間甩身版 E 項只有 5/15 → **不是 prompt 的問題**
3. 麵粉在深色木地板上非常清楚 → 因為那裡有對比

> **不要再硬攻白粉。** 排程上的 **D11S1 黑漆片**
> （`Taco Spilled Black Paint And Turned Into A Tiny Panda`）
> 是最容易做出「從毛上甩落」效果的題材，而且已有實證支持。
