# 三鳳中街商行系統

一套系統，整條街用。東信是第一家，不是唯一一家。

> ⚠ **這個資料夾跟 TOCO／Taco & Nova 影片產線無關。**
> 它會在這個 repo 裡，是因為工作分支開在這。這個 repo 是 **public**——
> 所以這裡只放系統設計，**不放任何店家的實際資料**（客戶、價格、往來紀錄）。
> 要不要搬到 `ai-company-os`（private）由 CEO 決定。

## 四個階段

1. **骨架**：多租戶底座、登入、切換商家 — 1–2 週 ← 資料庫部分就是這份 v0
2. **接單**：取代 Excel — 2–3 週
3. **庫存**：進出貨與盤點 — 2–3 週
4. **自動化**：客人端 LINE 下單 — 3–4 週

合計 8–12 週，趕上年節備貨期。

## 鐵律

1. **`service_role` key 永遠不准出現在前端或 LIFF。**那把鑰匙繞過全部 RLS。
2. **凡是「東信是這樣所以我寫死」的地方，都是未來的一次重做。**差異是資料，不是程式碼。
3. **店家的實際資料不進這個 public repo。**
