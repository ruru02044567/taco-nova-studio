# BGM 音樂庫 — 授權與出處

> 2026-08-22 建立。此前頻道只有兩首 BGM（apple-cider、happyclappy）在輪流用，
> 而 PUBLISH_GATE 規則 12 禁止「同一個音效檔連續兩支片重複」——再排下去必撞。
> 全部來自 Chosic（https://www.chosic.com/），**帶 UA 的 curl 可以抓，WebFetch 會 403**。

## 怎麼再抓新的

```bash
# 分類頁只給曲目頁連結（mp3 是 JS 動態載入的，HTML 裡沒有）
curl -s -A "Mozilla/5.0 ... Chrome/126.0 Safari/537.36" \
     "https://www.chosic.com/free-music/funny/" | grep -o 'download-audio/[0-9]*'
# 再抓曲目頁，裡面才有 wp-content/uploads/....mp3 的直連
```
可用的分類：`funny` / `happy` / `comedy` / `cartoon`（`kids` 和 `playful` 這兩個頁面沒有曲目）。

## 🔴 選曲一律靠量測，不憑曲名

這次實證了 PUBLISH_GATE 規則 12 那句「選曲靠量測不憑曲名」：

**Sneaky Snitch（Kevin MacLeod）名字最對「偷偷幹壞事」的人設，量下去卻是低頻 58.8%** ——
那是潛行、陰謀的音色，不是歡樂闖禍。跟 8/22 配樂變鬼片是同一個病根（低頻壓過頭）。

量測指令在 `_scratch` 的 `get_bgm.py`，判準：**低頻 < 30%、中頻 > 50%、起音密度 > 4.4/秒**
（現有兩首的實測值：apple-cider 低 31.7/中 34.1/起音 6.32；happyclappy 低 33.8/中 44.2/起音 4.07）。

## ⛔ `_有ContentID風險\` 裡的不要用

`quirky-dog.mp3`、`scheming-weasel.mp3`（Kevin MacLeod）——曲風其實很對狗片，
但 **incompetech 官網明講他的音樂已主動註冊進 Content ID**
（https://incompetech.com/music/royalty-free/youtube-contentid.html）：
> 會收到來自 YouTube 的 claim，通常 72 小時內解除，且必須在說明欄標名。

這頻道是 Made for Kids、收益本來就低，不值得每支片去處理一次 claim。留著檔案只是為了
記錄「查過了、結論是不要用」，不要下次又抓一次。
