## ⚠️ 這包不是影片裡那 40 種笑聲

賢賢看的影片是《抖音 40種 抖音笑聲 抖音音效》，但留言區那個下載連結指向的是
**另一包**「常用100種音效」。兩者編號**對不起來**，已用兩種方法驗證：

1. 振幅包絡相關性：對照組（比對影片的錯誤位置）分數反而更高 → 方法無鑑別力
2. **時長序列比對**（決定性）：把影片用靜音偵測切成 42 段聲音，逐一比對檔案 1–15
   的時長，**只有 1/15 吻合**

結論：想要影片裡那 40 種笑聲，這個連結拿不到。

## 現況

- `常用100種音效/`：原始 `.wmv`（wmav2 音訊 44.1kHz 立體聲 ＋ 一軌黑底浮水印畫面）
- `mp3/`：已抽出的純音訊，`ffmpeg -vn -c:a libmp3lame -q:a 2`

**只有 55 / 100 個檔**。Google Drive 的匿名下載有流量上限，抓到第 55 個就被擋，
`--continue` 重試兩次都沒有再進帳。

已下載：1–61（缺 7、8、9）＋ 100
缺號：7, 8, 9, 62–99（共 45 個編號、32 個檔，部分檔是併號如 `81-87.wmv`）

檔案 ID 清單留在 scratchpad 的 `missing.txt`；流量限制通常隔天解除，屆時重跑：

```bash
cd "…/sfx/77音效-常用100種"
python -m gdown --folder --continue "https://drive.google.com/drive/folders/1hQYE8eYznCricRVGtMq_L9p9I7pvpt5e"
```

用 Google Drive API（MCP）逐檔抓也可以繞過限制，但回傳的是 base64，
單一個 213KB 的檔就要燒掉約 7 萬 token，不划算，別走這條。

## ⚠️ 版權風險（發布前務必想清楚）

頻道說明欄寫「免費音效、可用於影片剪輯」，但這類「抖音罐頭音效」裡面
常混有電影／動畫的原始片段（影片中第 5 號就是「小小兵／小黃人」＝環球影業的角色）。

Taco & Nova 是**要走營利**的頻道，用到這種素材可能被 Content ID 認領，
輕則收益被抽走、重則影響頻道狀態。

**建議**：`sfx/lib/`（Sonniss GDC 官方釋出、可商用免標註）優先用，這包當草稿或
非營利用途的備案。真的要用這包，先確認該段聲音不是取自受保護的作品。
