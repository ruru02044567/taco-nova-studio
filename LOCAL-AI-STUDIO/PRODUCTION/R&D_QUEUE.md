## R&D-02：V2 訓練參數調整

| 參數 | V1 | V2 | 為什麼 |
|---|---|---|---|
| learning rate | 1e-4 | **5e-5** | V1 可用權重區間只有 0.25–0.45 太窄 |
| 步數 | 1000 | **1500** | lr 減半要補回來 |
| 存檔點 | 每 250 | 每 300 | 5 個檢查點方便挑 |
| rank / alpha | 16 / 8 | 不變 | |
| 底模型 | RealVisXL Lightning | 不變 | |

**caption 原則**：角色描述固定不變（燒進觸發詞），
**場景狀態必須逐張寫明且互相不同**（才剝得掉）。
V1 的失敗不是沒寫場景，是 5 張的場景全一樣、沒有對照組。
