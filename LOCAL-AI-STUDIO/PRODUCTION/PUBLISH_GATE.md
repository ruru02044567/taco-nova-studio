# PUBLISH_GATE — 可發片最低標準

> 建立 2026-08-13｜**這份是硬性門檻，不是建議。任一條不過就是 REGENERATE。**

## 檢查程序（每支影片必跑）

抽 6 幀：`0s / 1s / 2s / 3s / 4s / 最後一幀`（長片按比例分佈），排成 contact sheet 後逐項對。

```bash
for t in 0.05 2.0 4.0 6.0 8.0 9.9; do
  ffmpeg -v error -y -ss $t -i <影片> -frames:v 1 "_gate/t$t.png"
done
```

## 九條硬性規則（全部要過）

| # | 規則 | 判定方式 |
|---|---|---|
| 1 | 主角身份不能錯 | Taco 必須是純白短毛吉娃娃 |
| 2 | 動物種類不能錯 | **Nova 必須是哈士奇，不能是博美／狐狸犬** |
| 3 | 角色不能換臉 | 全片同一張臉，不得中途變形 |
| 4 | 場景不能嚴重漂移 | 沙發／植栽／地板／窗戶位置一致 |
| 5 | 動作不能嚴重變形 | 無多出的肢體、無融化、無扭曲 |
| 6 | 故事必須看得懂 | 災難主體必須在畫面上成立 |
| 7 | 第一秒必須能理解 | Shorts 沒封面，首幀就是一切 |
| 8 | 不得出現明顯 AI 災難 | 無幻覺動物、無憑空出現的肢體 |
| 9 | 必須是直式 | 1080×1920 / 24fps |

## ✅ 允許的變化（不構成退回理由）

- 小幅度毛髮、毛色深淺變化
- 尾巴蓬鬆度變化
- 配件細節（吊牌形狀、項圈材質詮釋）
- 非核心背景細節
- 表情變化（瞇眼 ↔ 圓眼）——那是演出，不是身份

## ❌ 禁止（一條就退回）

- **Nova 變成博美／狐狸犬／其他犬種**
- Taco 變成其他犬種
- 主要角色消失
- 故事關鍵物件消失（麵粉、酒漬、盆栽土⋯⋯）
- 嚴重閃爍、嚴重變形
- **吊牌上出現英文名字**（LUNA / TITO / Milo 都出現過）

## 🔴 規則 10：非預期讀法（2026-08-13 新增，血淚）

**逐格檢查會漏掉「動作連起來看才浮現的意思」。**

D4S1 麵粉片九項全過，我判 PASS，賢賢一看就說「像 Taco 在吐白粉」——他是對的。

單格看：狗低頭聞地上的麵粉。
連起來看：低頭 → 白粉扇形**從鼻口向外擴散** → 這是嘔吐／噴出的視覺語法。

**而且白粉 ＋ 動物 ＋ 嘴，在 YouTube 上是會被誤判的組合。**

### 必做的檢查

抽完 6 格之後，**再針對「動作最大的那 3 秒」抽 0.5 秒間隔的密集幀**，然後問三個問題：

1. 粉塵／液體／碎屑的**擴散起點**在哪？如果起點是嘴、屁股、生殖器附近 → **退回**
2. 把這段動作講給沒看過腳本的人聽，他會講出跟標題一樣的故事嗎？
3. 有沒有任何一種讀法會踩到平台紅線？（藥物、排泄、傷害動物）

### 已知的踩雷組合

| 畫面 | 會被讀成 |
|---|---|
| 白色粉末從嘴部附近擴散 | 嘔吐／吸食毒品 |
| 深色液體從後方擴散 | 排泄 |
| 狗躺著不動 ＋ 紅色液體 | 受傷／死亡 |

## 🔴 規則 11：音效必須對應畫面上看得見的事件（2026-08-19 新增，血淚）

**沒有畫面根據的音效就是噪音。** 每一個事件音，檢查者必須能指著畫面回答
「這一聲是那個動作發出的」。對不上就拿掉——寧可安靜，不准亂配。

- 出處：D9S1 12 秒版在剪接點放了一聲泥巴「啪唧」，但畫面上沒有任何東西
  掉落或噴濺，賢賢一句「5-6 秒的聲音很奇怪」直接抓出。同日並發現
  mix.py 的 atempo bug 讓已發布四支的事件音全堆在 0 秒——四支的音畫
  從來沒對上過（賢賢的原話：「聲音超奇怪」）。
- 9 分標準片（Chihuahua Pushes Remote）的每一聲都有畫面根據：
  推遙控器的摩擦（看得見推）、落地咚（看得見掉）、Nova 吼（看得見抬頭張嘴）。
- 附帶規則：**靜止的角色不可以有張嘴型的叫聲**（嗚咽、吠）；閉嘴能發的
  鼻息、低哼才允許。

## 🔴 規則 12：聲音結構量測比對對標（2026-08-19 新增，同日依實測改版）

> ⚠️ 初版照「9 分片＝稀疏靜音」模型寫，**同日拆對標頻道三支實測後推翻**：
> Tim & Jeffy 每支都是歡樂 BGM 鋪滿（賢賢先聽出來，頻譜證實）。保留兩種合格 profile。

**Profile A：音樂驅動（對標主流，預設用這個）** — 實測 tj1-3：

| 對標實測 | 要求 |
|---|---|
| 整體平均 -19.5～-22.9 dB | 成品整體 mean 落在 -25～-18 dB |
| 頻譜鋪滿：節奏直紋＋低頻地基 | 發前畫 showspectrumpic 對照，要「填滿」不能大片黑 |
| BGM 必須 CC0（Made for Kids 收益低，Content ID 扣不起） | 選曲靠量測不憑曲名（卡通農場教訓） |
| 人聲／叫聲 punchline 要穿透 | BGM 在 punchline 段自動 duck（volume enable 區段） |

**Profile B：寫實稀疏（賢賢 9 分片那型，特殊題材用）**：
開場首秒 < -60 dB；事件 ≤ 4 個、其餘貼地板；主事件峰 -30～-15 dB。

兩個 profile 共通：mix.build 帶 target_lufs=None（不准無腦拉 -14）。

- 同一個音效檔**連續兩支片重複使用 → FAIL**（聽感指紋重複，賢賢一耳抓出四支同款）。
  音效庫有一萬個聲音（sonniss_index.json），用 pick.py 找新的。
- 量測指令：抽 wav 後 numpy 0.5s RMS（作法見 2026-08-19 對話），或
  `ffmpeg -ss A -to B -af volumedetect`。
