# PUBLISH_GATE — 可發片最低標準

> 建立 2026-08-13｜**這份是硬性門檻，不是建議。任一條不過就是 REGENERATE。**

## 檢查程序（每支影片必跑）

抽 6 幀：`0s / 1s / 2s / 3s / 4s / 最後一幀`（長片按比例分佈），排成 contact sheet 後逐項對。

```bash
for t in 0.05 2.0 4.0 6.0 8.0 9.9; do
  ffmpeg -v error -y -ss $t -i <影片> -frames:v 1 "_gate/t$t.png"
done
```

## 九條硬性規則（全部要過）

| # | 規則 | 判定方式 |
|---|---|---|
| 1 | 主角身份不能錯 | Taco 必須是純白短毛吉娃娃 |
| 2 | 動物種類不能錯 | **Nova 必須是哈士奇，不能是博美／狐狸犬** |
| 3 | 角色不能換臉 | 全片同一張臉，不得中途變形 |
| 4 | 場景不能嚴重漂移 | 沙發／植栽／地板／窗戶位置一致 |
| 5 | 動作不能嚴重變形 | 無多出的肢體、無融化、無扭曲 |
| 6 | 故事必須看得懂 | 災難主體必須在畫面上成立 |
| 7 | 第一秒必須能理解 | Shorts 沒封面，首幀就是一切 |
| 8 | 不得出現明顯 AI 災難 | 無幻覺動物、無憑空出現的肢體 |
| 9 | 必須是直式 | 1080×1920 / 24fps |

## ✅ 允許的變化（不構成退回理由）

- 小幅度毛髮、毛色深淺變化
- 尾巴蓬鬆度變化
- 配件細節（吊牌形狀、項圈材質詮釋）
- 非核心背景細節
- 表情變化（瞇眼 ↔ 圓眼）——那是演出，不是身份

## ❌ 禁止（一條就退回）

- **Nova 變成博美／狐狸犬／其他犬種**
- Taco 變成其他犬種
- 主要角色消失
- 故事關鍵物件消失（麵粉、酒漬、盆栽土⋯⋯）
- 嚴重閃爍、嚴重變形
- **吊牌上出現英文名字**（LUNA / TITO / Milo 都出現過）

## 🔴 規則 10：非預期讀法（2026-08-13 新增，血淚）

**逐格檢查會漏掉「動作連起來看才浮現的意思」。**

D4S1 麵粉片九項全過，我判 PASS，賢賢一看就說「像 Taco 在吐白粉」——他是對的。

單格看：狗低頭聞地上的麵粉。
連起來看：低頭 → 白粉扇形**從鼻口向外擴散** → 這是嘔吐／噴出的視覺語法。

**而且白粉 ＋ 動物 ＋ 嘴，在 YouTube 上是會被誤判的組合。**

### 必做的檢查

抽完 6 格之後，**再針對「動作最大的那 3 秒」抽 0.5 秒間隔的密集幀**，然後問三個問題：

1. 粉塵／液體／碎屑的**擴散起點**在哪？如果起點是嘴、屁股、生殖器附近 → **退回**
2. 把這段動作講給沒看過腳本的人聽，他會講出跟標題一樣的故事嗎？
3. 有沒有任何一種讀法會踩到平台紅線？（藥物、排泄、傷害動物）

### 已知的踩雷組合

| 畫面 | 會被讀成 |
|---|---|
| 白色粉末從嘴部附近擴散 | 嘔吐／吸食毒品 |
| 深色液體從後方擴散 | 排泄 |
| 狗躺著不動 ＋ 紅色液體 | 受傷／死亡 |

## 判定

- 十條全過 → **PUBLISH**
- 任一條不過 → **REGENERATE**
- 只有「允許的變化」有落差 → **PUBLISH**
